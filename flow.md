### 1. RAG From Scratch — LangChain

**Start here.** Covers indexing, retrieval, generation, Multi-Query, Fusion, Decomposition, Step-Back, HyDE, routing, RAPTOR, ColBERT. ([GitHub][1])

### 2. Advanced RAG — Sunny Savita

**Coding topics:** Vector DB → BM25 → Dense Retrieval → Hybrid Search → MMR → Self Query → Parent Document → Sentence Window → Contextual Compression → Reranking → RAG Fusion. ([YouTube][2])

[🎥 Advanced RAG — Retrieval & Reranking Full Course](https://www.youtube.com/watch?v=_kpxLkH5vY0&utm_source=chatgpt.com)

### 3. Production RAG — freeCodeCamp

**Most important for job-ready.** Covers document loading, chunking, embeddings, Chroma, similarity search, basic RAG, debugging, hybrid search, LangSmith, optimization, scaling, Supabase + pgvector, FastAPI, LangGraph, security, contextual retrieval, agentic RAG, GraphRAG and multimodal RAG. ([YouTube][3])
